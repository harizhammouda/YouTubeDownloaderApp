YouTube Downloader Program Help Center

How to Download a Video or Audio from YouTube ?

1. Open YouTube and search for the video you want to download.
Copy the video link using the share button.

2. Click on "Paste" and the link will be pasted directly.

3. Wait until it finishes verifying the video link.

4. After verification, the video name appears here. The program is now ready to download the video.

5. After that, select the save path and download type (MP4, MP3, video, or audio). If it's a video,
choose the download resolution, then click "Download" to start.

6. Congratulations, the download is complete!

What is the difference between OPUS and MP3?

✓ OPUS: A modern audio format with high quality and smaller file size than MP3. Great for music and speech, but it does not support thumbnail images.
✓ MP3: A popular audio format supported by most devices and software. Slightly larger than OPUS at the same quality, but it can include thumbnail images.
✓ Which to choose? Pick OPUS for better quality and smaller size in storagem if you don’t need a thumbnail. Choose MP3 for maximum compatibility or if you want a thumbnail.

What is the function of the reload icon ?

The program is under development, so it is likely and normal for errors and glitches to appear.
Therefore, the function of this button is to reset the program from the beginning.
Also, suppose you want to download again: paste the link and wait, and the video title will appear.
In this case, if you want to paste another link, clear it with the "X" icon and paste a new link.
However, if you continue to modify the download settings here, you need to click the reload icon to paste a new link.
This is one of the issues that the reload icon resolves.
